# FreeRTOS_lectures
In this repository I will gain skills that enable me to
develop embedded systems using RTOS.

## Motivation

In previous projects and work e.g. as student assistant I
already developed software for embedded systems. These
systems, however, all used a super-loop architecture. 

The logical next step in embedded development is the use of
real time operating systems (RTOS). These enable the systems
to meet hard timing requirements. This is useful for many
applications such as safety critical tasks or control tasks. 

## Method

I will be learning to develop software using [FreeRTOS](https://www.freertos.org/)
first. To achieve this goal the 12 lecture [course from
DigiKey](https://www.youtube.com/playlist?list=PLEBQazB0HUyQ4hAPU1cJED6t3DU0h34bz) will be used as guideline. This repository may
include a final project in the end which implements
knowledge gained in the learning process. 

The embedded system used for this project is an ESP32
AZ-delivery dev kit. The programming will be performed with
[platformIO](https://platformio.org/). For each lecture
there will be a separate project with code to solve the
problems.
